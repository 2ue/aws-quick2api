目标：通过管理台手动选择「yuanzhang JSON 格式」，导入顶层 `accounts` 数组、每项包含 `session` 和 `upstream` 的备份文件。文件上传与文本粘贴使用同一入口。默认仍为原生 JSON 备份；原生导入接口不自动识别此格式。

实现约定：

- 新增 `POST /v1/admin/keys/import-yuanzhang-json`，沿用管理员鉴权与 CSRF 保护。

- 保留备注和停用状态；全批次格式、必填刷新字段、AWS Host 与独立代理预校验通过后才入池。

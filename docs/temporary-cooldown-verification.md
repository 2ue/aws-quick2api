## 行为

- 通用 usage-limit 回复与429归为临时限制，账号保持启用，默认冷却300秒；管理台与管理API支持1–86400秒。
- 上游明确恢复时间优先，短时 session reset 与月度 billing reset 分开处理。默认值只作用于之后触发的冷却。
- 尚未产生真实输出时，同模型原请求最多尝试五个账号；已产生正文、真实思考或工具调用不重新执行。
- 冷却与配置写回挂载 `.env`，重启保留，到期恢复。所有账号冷却导致等待超时，返回429和实际剩余等待时间。
- 真正额度耗尽按明确重置时间或账期暂停；时间未知时一小时后允许探测。手动停用和认证失败不会被额度恢复覆盖。
- 仅将旧版通用 usage-limit/session burst 误停用迁移为启用并临时冷却。
